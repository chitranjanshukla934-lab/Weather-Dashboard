# Weather Dashboard

A real-time weather dashboard built using HTML, CSS, JavaScript and OpenWeather API.

## Features

- Search weather by city name
- Real-time temperature data
- Weather condition description
- Weather icons
- Humidity information
- Wind speed
- Feels like temperature
- Atmospheric pressure
- Visibility
- Sunrise and sunset timing
- Responsive design

## Technologies Used

- HTML5
- CSS3
- JavaScript
- OpenWeather API

## Project Preview

A responsive weather application that fetches live weather information using API integration.

## How It Works

1. User enters a city name.
2. JavaScript sends a request to OpenWeather API.
3. API returns real-time weather data.
4. Weather information is displayed dynamically.
